Laboratory Exercises

Lab 1 – UI

Designed a responsive Jetpack Compose interface.

This lab helped me understand layouts, spacing and UI composition, forming the basis for HealthPal.

Lab 2 – Interaction

Implemented interaction and state management.

I learned how user input updates the interface dynamically, improving the user experience.

Lab 3 – Material Design

Applied Material Design 3 components.

Using Material Design improved consistency, accessibility and the professional appearance of the app.

Lab 4 – Navigation

Created multi-screen navigation.

This lab introduced Navigation Compose, allowing the application to scale into multiple interconnected screens.

Lab 5 – Room

Implemented Room Database.

I learned persistent local storage using Room and strengthened my understanding of MVVM architecture.

Project 1

HealthPal — Project 1

Problem Statement
Many of the new generation does not do any health tracking due to each app tracking only one thing at a time. HealthPal combines multiple health trackers into one application to encourage healthier lifestyles.

Reflection
Project 1 allowed me to integrate the concepts from previous labs into a complete Android application. I gained valuable experience designing interfaces, implementing navigation and developing a user-friendly health tracker.

Project 2

HealthPal — Project 2

Problem Statement
To encourage more people in keeping track of their health, HealthPal now integrates Room Database, Firebase Cloud, APIs, sensors and community support to create a smarter health companion.

Reflection
Project 2 expanded my understanding of full-stack Android development by combining local persistence, cloud synchronization and live internet data. It demonstrated how multiple technologies work together to create a practical mobile application.

Throughout this course I progressed from designing simple interfaces to building a complete health application.
